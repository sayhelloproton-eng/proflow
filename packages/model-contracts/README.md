# @tomflow/proflow-model-contracts

- Module: `model-contracts`
- Kind: `library`
- Owner: Model & Reasoning

Provides the frozen `infer`/`getRuntimeStatus` boundary schemas, versioned ReasoningSpec association, capability profiles, constrained Capability Proposal validation, and compatibility checks. The same typed inference boundary is used for exceptional Task diagnostics and bounded System Observer assessments; batching/carry-forward/drill-down/global-synthesis remain caller/application responsibilities. It executes no inference, owns no assessment store, and owns no Effect.
