# Knowledge (DEFERRED in ProFlow v1)

OpenAI Custom GPT supports Knowledge files, but ProFlow v1 intentionally does **not** make Role Knowledge/specialization part of setup, READY, runtime routing, or verification. The three v1 Agent Packages remain generic roles.

This directory is retained only as future specialization material/documentation; it must not create a Knowledge Service/Router/Registry, and no v1 deployment flow may require uploading it. Dynamic Task documents, source context, logs, test results, patches, and evidence remain Task/Execution-owned and are provided to the current Worker through formal Actions/File Bridge when needed.
