# 新仓库实施顺序、停止门与非目标

## 1. 固定实施顺序

```text
R1 Docs truth
→ R2 Module Contract/Template/Conformance/Skill + Module seams
→ R3 Platform CLI seven-command refactor
→ R4 Tests + simulated human Golden Path
→ STOP
```

不增加第五批。

## 2. R1 STOP gate

Active/normative 当前文档中：`platform modules` 作为当前命令 = 0；Platform preflight/verify/doctor/Plan-Apply 当前流程 = 0；`configStatus/missingConfig` 当前标准状态 = 0；标准指导文档只有 DOCS/SETUP。

## 四步实施顺序（强制）

1. **文档先对齐**：先更新全部 active/normative 真源，冻结 setup 全量聚合、Module 自闭环和最短配置路径；文档未对齐不得进入实现。
2. **资源准备**：先更新 Module Template / Module Skill，再更新各业务 Module 的 `SETUP.md` 与 package-owned setup executable/verify；不碰业务服务逻辑。
3. **Platform 命令实现**：按冻结规范实现七命令，尤其 `platform setup` 只做全量发现、排序、转发与聚合，不理解包内步骤。
4. **测试与真实验收**：更新测试 → gates → version/publish → Registry Fresh Workspace 七命令真实测试 → 人工验收。

四步必须顺序执行，不得用后一步实现反向定义前一步规范。

## 3. R2 STOP gate

24/24 governed Module 对齐七标准能力；24/24 有 `DOCS.md` 与 `SETUP.md`；15 个旧 `CONFIGURATION.md` 清零；descriptor/manifest/adapter conformance mismatch = 0；若需进入业务源码，立即 `DOMAIN_BLOCKER`。

## 4. R3 STOP gate

exactly seven Platform commands；old routes = 0；`configByModuleRef`/production binding middleman = 0；Platform private config loader = 0；Platform preflight/validate = 0；install/uninstall 确实调用 Module.install/uninstall；status/setup/docs/start/stop 均只 generic forward/aggregate。

## 5. R4 STOP gate

obsolete management expectations = 0；七命令 contract failures = 0；Module governance failures = 0；simulated human Golden Path blocker = 0；generated governance evidence 只能由 owner script 重生成。

## 6. 模拟人工 Golden Path

```text
platform install
→ platform status
→ platform docs
→ platform setup（每次都全量聚合全部未 READY Module，可重入直到 READY）
→ platform status
→ platform start
→ platform status
→ platform stop
→ platform uninstall
```

## 7. 非目标

- 不重新设计 Browser/Model/Execution/Gateway/Task/Agent 领域业务；
- 不禁止 Module 自身真实 extra command；
- 不增加第八个 Platform 标准命令；
- 不恢复 repair/retry/rollback/resume engine；
- 不把 Module private config/shared fact 搬进 Platform；
- 不做 release/version/Registry publish；
- 不在 simulated acceptance 后继续无限扩散整改。
