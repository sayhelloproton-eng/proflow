## 4. Domain Gates

- Contract/Package 基线：Role/Worker/Collaboration schema、Gateway transport、无 deep import/second truth。
- Role Registry/Credential + Collaboration 串行/idempotency。
- 三角色 Agent Package materialization + Gateway auth/File Bridge/consequential。
- Real-2 Deployment Provisioning：Extension 安装真实 heartbeat、三个 Agent 自动创建/更新 Private GPT、Knowledge ZIP、`gpt-5-6`、required Capabilities、Action Schema、真实 g-id、Role register、动态 Auth materialization、reentrant no-duplicate。
- Worker provisioning/WAKE/delivery/reopen/same-worker。
- 真实 Custom GPT Carrier E2E + reload/timeout/expired locator recovery；Playwright/MCP feasibility 不替代产品 Extension 路径。

## 5. Domain Test Responsibility

- Domain Behavior：只证明本领域状态/invariant/idempotency/concurrency/error/recovery。
- Contract：Provider + Consumer 双侧，runtime schema 不能只靠 TS type。
- Integration：尽量使用真实 storage/serializer/schema/adapter；昂贵外部依赖才 fake。
- Real Acceptance：如果被验收能力就是 Browser/Carrier/Local Effect/Model/External Resource 本身，则不能只 Mock。
- Conformance：只证明平台治理结构，不替代 Domain PASS。
