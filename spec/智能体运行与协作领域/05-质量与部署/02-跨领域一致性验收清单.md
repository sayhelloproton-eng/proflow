# 智能体运行与协作领域｜跨领域一致性验收清单

> 用于实现/集成/E2E检查，不维护提案历史。

## 1. Task / New Task

- [ ] Extension 是 v1 New Task唯一主入口：先 `createTask(PENDING)`，再建立三 Worker。
- [ ] `TaskRoleBinding`唯一owner是Task；Agent不保存第二份 role→worker business binding。
- [ ] Binding包含 `agentPackageRef/roleRef/workerRef/conversationLocator`；Task不保存tab/frame。
- [ ] Product/Dev/Test在New Task阶段一次建立；Product可先讨论Requirement，Dev/Test bind-only IDLE。
- [ ] partial success只补缺失Worker。
- [ ] readiness由Requirement + 3 bindings + prerequisites确定，不依赖human authorization fact。
- [ ] Extension确认后调用`startTask`；没有Task Approval entity/`authorizeTask`。
- [ ] Node READY先由Task Observer WAKE；Worker收到后正式`startNode`。
- [ ] `startNode`按`requiredAgentPackageRef → TaskRoleBinding.workerRef`解析，不接受任意Worker。
- [ ] reopen same workerRef/Conversation，runNo+1。
- [ ] terminal binding保留，Task Observer stop-driving。

## 2. Agent Identity / Credential

- [ ] packageName/agentPackageRef=logical Role；roleRef=deployed GPT；workerRef=Task Conversation c-id。
- [ ] one Role one random credential；credential≠packageName。
- [ ] Browser不持有/校验Role credential。
- [ ] Action不依赖stable c-id；Browser负责observe/bind Conversation identity。

## 3. Browser / Execution Carrier

- [ ] Browser Extension ownership仍属Execution。
- [ ] Background Carrier Controller通过typed command做CREATE/RESTORE/WAKE/observe。
- [ ] DOM-first programmatic input/submit；无frame registry/iframe topology/coordinate automation。
- [ ] WAKE仅minimal `taskId/nodeId/runNo/workerRef/trigger`。
- [ ] physical delivery不等于Node/Effect success。
- [ ] submit uncertainty先same Conversation reality reconciliation；UNKNOWN禁止blind replay。
- [ ]普通文件传输不经Browser DOM，走File Bridge + Execution materialization。

## 4. Worker Turn / GPT Native

- [ ] 一个WAKE允许同一Conversation内0..N sequential Actions；无Action-level Browser scheduler/“继续”。
- [ ] fresh formal facts按需Action读取；Conversation memory不代替current owner state/version。
- [ ] File Bridge是transport，Context Pack/Patch为Execution Artifact subtype。
- [ ] Code Interpreter处理bounded context/patch/report，不直接修改repo。
- [ ] Web Search负责public research；Execution Network负责local/private/credentialed/deterministic engineering。

## 5. Collaboration

- [ ] GPT-facing只需`askPeer/replyPeer`逻辑动作。
- [ ] 同Task固定binding直接解析target worker，不做dynamic agent discovery。
- [ ] Message Center拥有durable message/reply；physical delivery经Execution/Carrier。
- [ ] Peer pending不自动Task WAIT；reply ready后Task Observer/Delivery path WAKE source。
- [ ] Collaboration不自动complete/wait/reopen Task。

## 6. Agent Gateway

- [ ] Custom GPT只通过Gateway公网入口。
- [ ] credential→authenticatedRoleRef；body自报roleRef不可信。
- [ ] no arbitrary custom headers；identity/idempotency/version/correlation在typed body/path/query。
- [ ] 45s / `<100,000 chars` / real 429/5xx hard guards。
- [ ] Gateway只auth/validate/normalize/route/serialize，无Tool Router AI/业务persistence。

## 7. File Bridge

- [ ] `openaiFileIdRefs` normalization/count/size/aggregate/fetch/SSRF/MIME/path gates。
- [ ] Execution做physical materialization/hash/Artifact；Gateway不变File Store。
- [ ] `openaiFileResponse` inline→relay、10 files/10MB/no image-video、TTL/scope/token约束。
- [ ] image asymmetry不删除Browser/Execution screenshot→Vision路径。

## 8. Approval / Permission

- [ ] Task start confirmation channel ≠ Task Approval fact。
- [ ] Execution dangerous-effect Approval由Execution owner持有。
- [ ] Deployment ACTION_REQUIRED(_WEB)必须human action后re-observe。
- [ ] routine Action显式`x-openai-isConsequential:false`；Always Allow主链与Execution Approval独立。

## 9. Observer / Model

- [ ] Task Observer deterministic；单Task anomaly才REASON diagnostics，no workflow authority。
- [ ] System Observer消费8类bounded views并低优先级REASON；支持batch/carry-forward/drill-down/global synthesis。
- [ ] System assessment是derived artifact，不覆盖Owner facts。
- [ ] FAST/REASON/Vision不是Worker；model failure不能阻断Task主链。

## 10. Deployment

- [ ] Role READY按behavior/capability/auth/actual verification，不按exact model id。
- [ ] GPT create/edit保持ACTION_REQUIRED_WEB。
- [ ] Action Auth/File Bridge/Code Interpreter/Web Search/Always Allow纳入carrier requirements/doctor/verify。

## 11. 最终 E2E

必须真实证明J0→J6、三Worker partial recovery、same-worker reopen、multi-action Worker Turn、File Bridge、Collaboration async wake、UNKNOWN no-replay、terminal no-ghost-wake和Observer边界。
