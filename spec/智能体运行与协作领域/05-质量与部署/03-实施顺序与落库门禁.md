# 智能体运行与协作领域｜实施顺序与落库门禁

> 当前目标：将既有Agent/Gateway/3 Role packages对齐J0→J6、OpenAI native reuse与薄Carrier，不新增第二Agent Runtime或Browser orchestration体系。

## P0｜Contract / Identity 基线

- [ ] 3 fixed Agent Packages：Product / Controller-Dev / Test-Ops。
- [ ] packageName/roleRef/credential/workerRef/conversationLocator职责分离。
- [ ] Product GPT主链无`createTask/listRegisteredRoles/getRegisteredRole`。
- [ ] Agent Public Contract/Task/Execution/Deployment依赖均只走Public Contract。

## P1｜Role Registry + Credential

- [ ] one package→one deployed roleRef registration。
- [ ] one Role→one random credential；rotate不改变roleRef。
- [ ] Browser local-platform-token与Role credential隔离。
- [ ] Registry query保留management/Deployment/Carrier lookup，不做Product dynamic discovery。

## P2｜Collaboration Message Center

- [ ] askPeer/replyPeer durable/idempotent。
- [ ] fixed Task binding解析target，不dynamic matching。
- [ ] physical delivery经Execution；uncertain delivery reality-first。
- [ ] Peer pending不自动Task WAIT；reply ready后WAKE source。

## P3｜Agent Packages / GPT Native

每包完成：

```text
metadata
fixed-context
memory baseline
actions/custom-gpt.openapi.yaml
carrier requirements
native capability usage guidance
```

- [ ] File Bridge / Code Interpreter / Web Search优先规则明确。
- [ ] one Worker Turn 0..N Actions；无Action-level Browser scheduler。
- [ ] Knowledge specialization明确defer。

## P4｜Agent Gateway

- [ ] role Bearer auth / authenticatedRoleRef。
- [ ] typed body/path/query，不依赖arbitrary custom headers。
- [ ] 45s / <100k / 429/5xx。
- [ ] File Bridge input/output relay安全门。
- [ ] routine control/intent Action显式`x-openai-isConsequential:false`。
- [ ] Gateway无business/file persistence、无Tool Router AI。

## P5｜Extension-first New Task / Worker Binding

```text
Task.createTask(PENDING)
→ create/observe Product+Dev+Test Conversations
→ validate identity
→ bindTaskWorker ×3
→ Product Requirement
→ deterministic READY
```

门禁：partial failure只补missing Worker；Dev/Test bind-only IDLE；Browser tab alive不是Task readiness。

## P6｜READY / Wake / Worker Turn

- [ ] Task Observer读取drive projection deterministic决定wake/resume。
- [ ] Carrier RESTORE correct Conversation + minimal WAKE。
- [ ] Worker收到NODE_READY后正式`startNode`。
- [ ] one wake allows 0..N Actions；Browser不每Action“继续”。
- [ ] long Execution/Approval/Peer result ready后再WAKE same Worker。

## P7｜Task/System Observer integration

- [ ] Task Observer normal path no model；single-task ambiguity才REASON diagnostic。
- [ ] System Observer 8 bounded views + deterministic snapshot。
- [ ] concern batching + carry-forward + drill-down + global synthesis。
- [ ] lowest priority；model busy/unavailable only defer。
- [ ] assessment/recommendation无business write authority。

## P8｜真实 Carrier / OpenAI E2E

必须最终手工覆盖：

```text
J0 Role READY
→ J1 Extension New Task + 3 Workers
→ J2 start confirmation → startTask
→ J3 RESTORE/WAKE → Worker startNode
→ J4 multi-action/File Bridge/CI/Web Search/Execution/Collaboration
→ J5 async resume/reopen/recovery/UNKNOWN
→ J6 terminal no ghost wake
```

以及Always Allow、no custom headers、Browser c-id observation、image/Vision fallback。

## GO

- Contract/identity/auth gates PASS。
- Product main path无旧pre-Task createTask flow。
- same-task Worker binding/reopen/partial recovery可证明。
- Gateway/File Bridge security gates PASS。
- Observer无Owner越权。
- 真实External Carrier能力在最终E2E前不被fake PASS替代。

## STOP

- 需要Agent/Session/AgentRun/WorkerTurn business entity；
- 需要dynamic Agent discovery来完成固定三角色主链；
- 需要Browser转移出Execution ownership；
- 需要frame/iframe/persistent tab business identity；
- 需要Observer直接改Task/Execution；
- 需要model confidence绕过Policy；
- 需要把current implementation反向写成规范。
