# 02 · 总体架构、包、服务与运行拓扑

## 1. 包拆分

| 包 | 类型 | 主要职责 |
|---|---|---|
| `execution-contracts` | library | 内部 durable Execution / Browser Result/Evidence/Approval/UNKNOWN contract |
| `execution-runtime` | backend service | Browser/Carrier/Approval/UNKNOWN/materialization durable lifecycle |
| `execution-local` | local implementation library | Local Dev / Repomix / CodeGraph 本机实现 |
| `execution-browser-extension` | Chrome Extension | Browser Carrier、Deployment provisioning、独立 Local Tool Effect Gate/lane |

## 2. GPT-facing runtime topology

```text
Custom GPT
  ↓ Action
Agent Gateway
  ↓
ProFlow API / platform-host application
  ├─ Task / Document → Task Owner
  ├─ Peer            → Agent Owner
  └─ Tools
      ↓
      Browser Extension Local Tool lane
      /v1/local-tools/commands/*
      ↓
      local-tool bridge
      ↓
      execution-local
      ├─ Local Dev
      ├─ Repomix
      └─ CodeGraph
      ↓
      macOS
```

该链不经过 Execution Runtime，不产生 executionRef。

## 3. Browser durable topology

```text
backend internal Browser/Carrier request
→ execution-runtime（需要 durable semantics 时）
→ Browser Extension existing Browser lane
   /v1/commands/* + runBridgeLoop()
→ ChatGPT page reality/effect
→ Result/Evidence/UNKNOWN
```

## 4. Extension double-lane invariant

Browser lane 与 Local Tool lane 不共享 queue、pending、serial loop、dispatcher、timeout/backoff、readiness、locks、tab/session/Observer state。Local Tool 的慢 command/process 不得阻塞 Browser heartbeat/poll/WAKE/submit。

只允许共享 Extension identity、认证 primitive、基础 loopback config、通用日志 helper。

## 5. `execution-local` dependency direction

`execution-local` 不反向依赖 Browser/Task/Agent/Host。Browser Extension 的 local-tool bridge 调它；内部 Execution 如仍需某些低层 primitive，可以复用，但不得要求 Local Tools 反过来进入 Runtime。

## 6. Task progression

Task Observer deterministic progression + lost-trigger reconciliation 位于 backend application，不在 Extension service worker。Extension/page events只作 kick；bounded catch-up 最终发现 READY/RESUME。

## 7. Explicitly forbidden

- Gateway/Host/API → execution-local 直连；
- GPT Tool → execution-runtime；
- MCP Runtime/Server 进入产品主链；
- Local Tool 与 Browser command 共用串行 lane；
- Extension 拥有 Task progression scheduler；
- 为追求 0 loopback HTTP 绕过 Extension Effect Gate。
