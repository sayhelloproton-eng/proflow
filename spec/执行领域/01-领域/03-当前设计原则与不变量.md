# 执行领域｜当前设计原则与不变量

## 1. 领域定位

Execution **不是所有真实本机操作的唯一入口**。它只拥有需要 durable side-effect lifecycle 的内部 Effect：Browser/Carrier、physical delivery、Approval、UNKNOWN/recovery 与仍需 durable materialization 的内部场景。

GPT-facing 本地工程工具固定走：

```text
Action → Gateway → ProFlow API → Browser Extension
→ Local Tool lane → local-tool bridge → execution-local → macOS
```

## 2. 模型侧边界

模型只理解 `Task / Node / Document / Peer / Tools`。Capability / Execution lifecycle / executionRef / polling 不再作为 GPT 工作心智。

`executeCapability/getExecution/readExecutionOutput` 如仍存在，只属于平台内部 Execution contract。

## 3. Side Effect 安全不变量

对进入 durable Execution 的 Effect：

- 危险 Effect 在实际执行前持久化 intent / execution identity；
- Effect 已开始但现实不确定时进入 `UNKNOWN`；
- `UNKNOWN` 绝不 blind retry，先 reality verification；
- transport/click success 不等于 effect/business success；
- Approval 与 OpenAI Action confirmation 分离。

对 Local Tools：

- 所有 GPT-originated macOS 调用必须经过 Browser Extension Effect Gate；
- mutation/command lost response 返回 `TOOL_RESULT_UNKNOWN`，禁止自动重放；
- 通过 Local Dev read/status/Git diff/process status 等重新观察现实；
- 不创建 Execution Record 只是为了获得工具结果。

## 4. Browser / Local Tool 双 lane

Browser Extension 内必须隔离：

```text
Browser lane
/v1/commands/* → runBridgeLoop() → Browser/Carrier

Local Tool lane
/v1/local-tools/commands/* → runLocalToolBridgeLoop()
→ Local Tool dispatcher → execution-local
```

两条 lane 不共享 command queue、pending map、timeout、retry/backoff、dispatcher、锁、Browser tab/session 或 Observer state；最多共享 Extension identity、认证 primitive、loopback 基础配置和通用日志 helper。

## 5. Browser responsibilities

Browser/Carrier 继续负责 Conversation CREATE/RESTORE/WAKE、page reality、permission、submit/receipt、screenshot、physical delivery 与 Browser Effect recovery。

Task progression detector / lost-trigger reconciliation 不再运行在 MV3 background；backend application 读取 durable owner facts并做 bounded catch-up，Extension 只提供 Carrier/page reality 与低延迟 kick。

## 6. Local Tool boundaries

产品工具只有：

```text
Repomix   = 广域仓库上下文：pack / grep / read
CodeGraph = 代码结构关系：explore
Local Dev = 当前磁盘真值 + mutation + command + process reality
            read / list / search / mutate / run / process
```

Local Dev `search` 只做窄域实时 filename/literal/regex 查找；不复制 Repomix 的广域上下文聚合。Git/test/build/install 等 one-shot 操作统一走 `run`；进程/端口/长任务统一走 `process`。

## 7. `execution-local` 定位

`execution-local` 是本机工具实现扩展包：

```text
execution-local/
├─ local-dev/
├─ repomix/
└─ codegraph/
```

包名不代表 Local Tool 必须经过 `execution-runtime`。内部 durable Execution 若仍需要文件/materialization primitive，可以依赖底层 primitive；反向依赖 Browser/Task/Agent 业务模块禁止。

## 8. Tool implementation strategy

- Repomix：优先复用官方 Node library；CLI 只作必要 fallback。
- CodeGraph：优先复用官方 Node library；可保留 CLI/binary fallback。
- Local Dev：以 DesktopCommanderMCP 成熟 file/search/process 实现为上游参考，去掉 MCP transport，裁掉与 Repomix 重叠的广域读取，只保留精简 Tool contract。
- 本产品链不是 MCP，不引入 MCP Runtime / dynamic discovery。

## 9. Decision authority

```text
Owner current fact + hard safety policy
> deterministic validation
> bounded model diagnostic（确需时）
> human authorization（确需时）
```

Task/System diagnostic 不能直接成为 Task transition、Tool permission 或 Execution success。

## 10. 工程拓扑与 readiness

Model DOWN、旧 Execution Runtime DOWN、某一 Tool DOWN 不能被折叠为一个全局失败。Task/Peer/Local Tools 按自己的 operation dependency 判断 readiness；Local Tool lane DOWN 不得阻塞 Browser lane，Browser page problem 也不得污染独立 Local Tool implementation readiness。

## 2026-09-09 用户裁决：默认 Workspace 与 trusted command

Local Dev 使用 trusted local developer command 模型。Workspace 是 server-bound 默认操作范围，不是 OS sandbox。ProFlow 能明确识别的外部 path/cwd、跨 Workspace move/copy、另一个 repo 或显式外部文件参数，必须在 Effect 前由 Extension 向用户明确提示规范化越界目标；提示后继续执行，不等待批准，也不因缺少越界批准而拒绝。不能静默扩大默认范围。

获准的 pnpm/npm test/build/install、git、node/python、repo script/lifecycle/hook 继承当前 macOS 用户权限。平台不承诺阻止脚本内部访问 Workspace 外部；不要求 container、VM、mandatory sandbox 或新增 Approval Runtime。认证 Role×Tool×Operation、canonical path/symlink 检测、受保护 credential、env redaction、deadline、managed processRef、generation/digest 校验与 UNKNOWN no-blind-replay 继续有效。

越界提示关联当前 commandId/generation、Role、Workspace、Tool/operation、完整参数摘要和规范化越界目标；参数/目标变化时提示实际目标。提示无需用户确认，不引入 approved 字段或越界批准状态。Extension Effect Gate 仍校验身份、参数和 deadline；过期 command 不重启，UNKNOWN 不盲重放。提示不创建 Execution Record，也不赋予任意 PID 控制权。明确危险操作的独立确认规则继续有效。
