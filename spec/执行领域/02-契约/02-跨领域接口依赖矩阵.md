# 11 · Execution 跨领域接口与依赖矩阵

## 1. 总原则

Execution 只处理内部 durable effect，不成为 GPT Local Tools 的必经中间层；跨域事实只走 Owner Public Contract。

## 2. Matrix

| 方向 | 当前依赖 | Owner / 边界 |
|---|---|---|
| Execution → Task | durable Browser/Carrier effect 所需 Task/Node/run/worker binding 与 current scope | Task Public Contract |
| Execution → Agent | physical collaboration delivery 所需 Role/Worker/Message target | Agent Public Contract |
| Execution → Model | bounded risk/diagnostic（仅内部 durable effect 确有需要） | Model Public `infer` |
| Deployment → Execution | runtime/extension/local-tool implementation package lifecycle/config | owning Module |
| Gateway/API → Execution | **仅内部 Browser/Carrier/materialization 等 durable operation** | 不承载 GPT Local Tools |
| Gateway/API → Local Tools | typed Tool command → Browser Extension Local Tool lane | `AGENT-DOC-02-05` |
| Backend Reconciliation → Task/Agent/Carrier | deterministic progression detection + bounded catch-up | application layer；不写 Owner Store |

## 3. Local Tool hard boundary

```text
GPT Action
→ Gateway
→ ProFlow API
→ Browser Extension /v1/local-tools/commands/*
→ execution-local
→ macOS
```

Tool request 不带 Task/Node/Worker/Execution identity。Execution Runtime DOWN 不应让本来可用的 Local Tool 被全局拒绝。

## 4. Browser durable dependency

Browser/Carrier 的 CREATE/RESTORE/WAKE/physical delivery/Approval/UNKNOWN recovery 可继续进入 Execution durable lifecycle。Extension 只做物理页面 reality/effect，不拥有 Execution Record 或 Task truth。

## 5. Task Observer / Reconciliation

Task Observer deterministic decision 与 lost-trigger reconciliation 位于 backend application，不在 MV3 Extension background。它读取 Task/Agent/Execution/Collaboration current facts，产生 typed Carrier/Owner request；不直接写 Task/Agent/Execution Store。

Extension page event/reconnect 只可作为低延迟 kick，不能成为唯一 progression scheduler。

## 6. Model Contract

Model 只在内部 durable effect 的风险/UNKNOWN diagnostic 等受控场景按 caller policy调用；本地 Tool selection 由 Custom GPT 自身根据固定 Tool contract决定，不建设平台 Tool Router AI。

## 7. Deployment

Platform 只做 Module governance。Extension Browser lane 与 Local Tool lane 的 endpoint/token/readiness 由 owning modules materialize；secret 不进入 GPT schema。
