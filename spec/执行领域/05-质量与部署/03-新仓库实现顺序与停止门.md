# 14 · Execution 当前收口实施顺序与停止门

> 当前不是重新设计Execution，而是把Existing Core、Browser Carrier、Observer integration与OpenAI native capability对齐到第一版最终主链。当前代码不得反向修改规范。

## X0｜Contracts / Runtime Safety

- Execution contract/runtime schema；
- durable effect intent / Result/Evidence/UNKNOWN；
- Policy hard rules + Approval；
- X7 decision authority：Hard Rule > deterministic > FAST > REASON > Human authorization。

## X1｜Local typed capabilities

保持fs/git/process/network/shell等deterministic primitives与真实安全边界。它们可以作为Execution能力，不要求全部成为GPT-facing高频Actions。

## X2｜Artifact / File Bridge materialization

- Gateway input file refs → Execution bounded fetch/materialize/hash；
- Context Pack/Patch作为Artifact subtype；
- proposal artifact与apply Effect分离；
- transport failure不自动Execution UNKNOWN。

## X3｜Browser Carrier identity / page reality

实现：

```text
agentPackageRef + roleRef + workerRef + conversationLocator stable binding
transient tab/content runtime address
CREATE / RESTORE / WAKE
DOM-first observe/input/submit
screenshot→Vision fallback
```

禁止frame registry/iframe topology/persistent tab business identity。

## X4｜Extension New Task / Backend Task Reconciliation / Carrier

Extension application：

```text
Task UI / Approval-Alert UI
Background Carrier Controller
System Observer 页面侧能力
```

Backend application：

```text
Task Observer / Reconciliation
→ deterministic next-step
→ bounded catch-up
→ typed Carrier request
```

- New Task创建三Worker并partial recovery；
- Task progression normal path deterministic，lost trigger 由 backend bounded catch-up 补偿；
- Node READY 由 backend Reconciliation 形成 typed WAKE request，Extension 只做 restore/permission/submit/receipt/reality guard，Worker再`startNode`；
- async result/reply ready 先进入 Owner current facts，再由 backend Reconciliation 决定是否 wake same Worker；
- terminal stop-driving。

Task Observer异常REASON只诊断。

## X5｜Worker Turn / Collaboration / Permission

- one WAKE→0..N Actions；无per-action Browser continue；
- physical Collaboration delivery经Execution；
- ordinary shipped Actions 固定 `x-openai-isConsequential:false`，不依赖预配置 `Always Allow`；
- unexpected permission prompt只作为Carrier recovery；可信 `AUTO_ALLOW` 优先当前页面的 `allowAlways`，缺失时使用 `allow`，`allowOnce` 只供人工 Attention；
- Execution Approval仍独立。

## X6｜System Observer

同一Extension package内实现最低优先级System Observer：

```text
8 bounded views
→ compact snapshot
→ concern batching
→ phone REASON
→ carry-forward / drill-down
→ global synthesis
```

它不拥有Task/Execution/Agent facts；model busy只defer。

## X7｜Reliability / Final Non-E2E Gate

- CREATE/WAKE/delivery effect uncertainty reality-first；
- Browser real effect复用Execution durability，不建第二Runtime；
- logs/redaction/correlation；
- architecture gates：no frame/no browser business store/no observer authority。

## X8｜FINAL MANUAL E2E（最后）

真实Chrome/Custom GPT/Actions/Gateway/File Bridge/ordinary nonconsequential Action + unexpected Permission fallback/three-Worker J0→J6全链与故障恢复。

## STOP

若需要新增Browser第二业务Store/Effect Runtime、frame体系、action-level scheduler、System Observer scheduler、Task Observer normal-path model、或Model直接执行Effect，立即STOP。
