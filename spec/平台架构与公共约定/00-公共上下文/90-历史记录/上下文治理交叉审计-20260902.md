## 2. 交叉审计发现

治理后的第一版确实存在“原则保留、执行记忆压缩过度”的问题，主要包括：

- P0：`gptweb-mcp → tunnel-client → Playwright MCP Extension → 真实 Chrome` 的 runtime SOP 缺失。
- P0：Browser 工具连接页、真实 Chrome 复用、禁止旧 9229/CDP 回退等恢复语义缺失。
- P1：Custom GPT 的冻结创建 API、不可逆 `LIVE_CREATED` 恢复与 durable Role authority 不够明确。
- P1：CLI/PTY 已验证 `platform-setup.exp` 路径没有独立 Runbook。
- P1：Targeted Gate、dirty-tree 单包发布恢复的 canonical 入口缺失。
- P1：Real-3 J1～J4 只有业务语义图，没有真实 Side Panel / Owner / WAKE 执行入口。
- P1：Model Provider/Runtime 缺少明确 READY Authority，存在凭旧 mapping/setup 文件猜 READY 的风险。
- P1：稳定知识库残留具体 `0.1.x` 历史实例，可能被下一 Chat 误认成当前版本。
