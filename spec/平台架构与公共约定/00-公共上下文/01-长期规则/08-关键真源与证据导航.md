## 机械事实真源与取证工具

规范真源回答“应该是什么”；机械 authority 回答“现在实际上是什么”。不同层的事实不能互相冒充：

| 事实类型 | 当前 authority | 默认取证入口 |
|---|---|---|
| 仓库文件、Git diff/HEAD、测试/build | 当前工作树 / Git / 真实命令 | Local Dev |
| npm 已发布版本 | npm Registry exact/latest readback | Local Dev + 正式 npm 命令 |
| 用户 Workspace 安装/物化版本 | Product Workspace 当前文件与 package manager 事实 | Local Dev |
| 代码结构、调用链、ownership、blast radius | 当前源码关系；dirty tree 冲突时磁盘优先 | CodeGraph + Local Dev 交叉确认 |
| 大范围仓库上下文/迁移覆盖 | pack 时刻稳定上下文 | Repomix `outputId`；源码改动后旧 outputId 不再代表最新磁盘 |
| 普通 Web / ChatGPT / Tasks 用户现实 | 当前受控业务 Tab | Playwright `browser_tabs + snapshot + page screenshot` |
| `chrome://` / Extension privileged / 系统 UI | 当前真人可见 privileged UI | AX tree + screenshot |
| MCP runtime / relay / manager | `gptweb-mcp` 与唯一 manager 当前运行事实 | Tool-Runtime Runbook |

证据升级固定遵守：`现象层 reality → owning runtime/owner authority → structure → source modification → 回同一现象层复验`。源码、单测或 helper 返回值不能单独覆盖更高层用户现实。

历史 Chat 只用于解释“为什么”，不能覆盖这些当前正式真源。
