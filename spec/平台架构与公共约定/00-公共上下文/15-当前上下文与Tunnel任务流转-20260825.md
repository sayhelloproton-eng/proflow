## 3. Tunnel 独立任务边界

用户希望评估 OpenAI Secure MCP Tunnel 是否可以替换当前 Microsoft `dev-tunnel`。
已确认 OpenAI `tunnel-client 0.0.11` 的公开定位是 MCP/private server → OpenAI control plane 的 outbound tunnel；不能默认它是通用公网 HTTP reverse tunnel。

当前 `dev-tunnel` 的真实职责是：
`local agent-gateway → public HTTPS publicBaseUrl → Custom GPT Actions OpenAPI servers.url`。
Tunnel 任务第一阶段只允许做兼容性证明：
1. Secure MCP Tunnel 是否提供普通 HTTP Agent Gateway 可用的稳定公网 HTTPS URL；
2. 该 URL 是否能直接作为 Custom GPT Actions `servers.url`；
3. 是否支持当前任意 HTTP path/method，而非只支持 MCP JSON-RPC/channel；
4. 是否可以保持 Agent Gateway / Custom GPT Actions 合同完全不变。

若任一点不成立，立即 STOP：`OPENAI_TUNNEL_GENERAL_HTTP_INGRESS = NO`，代码零修改。不得为了迁就 Tunnel 把当前 Frozen Phase 3 架构静默改成 MCP Gateway。

若真实兼容性 PASS，才允许对 `dev-tunnel` 做最小 provider 替换；长期 runtime 优先 `tunnel-client runtimes connect`，并以 `runtimes status --json`、`/healthz`、`/readyz` 与真实 Gateway ingress proof 验收。

安全：不得读取、打印、提交 Admin Key、Runtime API Key、Tunnel token、Role credential；secret 只使用引用。

## 6. 配置自动化之后的 Real-3 顺序

Real-3 固定目标是 J0～J4，但 Real-2 已经完成真实 Role/Custom GPT identity，因此实际下一条主链从 J1 开始。

```text
J1：Task Orchestration + Browser Extension
Extension 创建 PENDING Task → 创建/观察/绑定 Product/Dev/Test 三个真实 Worker Conversation；partial success 只补缺失，不重复绑定。

J2：Task Orchestration
Requirement + bindings 满足后 Task READY；人工确认直接调用 startTask → ACTIVE，不创建第二套 Task approval/authorization fact。

J3：Task Orchestration Owner Projection + Browser Extension Task Observer/Carrier
Observer 只读发现 Node READY → RESTORE/WAKE 已绑定 Conversation → 物理 delivery 确认 → Worker 自己调用 startNode。Observer 不写 Task truth。

J4：Agent/Gateway + Browser Carrier + Execution/File boundary
同一 Worker Turn 支持 0..N Actions，不需要 Browser 每 Action 继续/唤醒；随后验证 Context Pack/File Bridge/Code Interpreter/Patch handoff 的边界。
```

Model Runtime 不是 J1～J4 正常调度者；正常 Task progression 必须 deterministic，不调用 REASON。模型只在单 Task ambiguity/UNKNOWN/重复 recovery failure 等场景提供 non-authoritative diagnostic。真正 FAST/REASON 手机模型与 Model E2E 属后续 Real-5。

因此配置自动化收尾后，Real-3 的第一验收领域应是：`task-orchestration` 为 Owner，`execution-browser-extension` 为真实 Carrier/Observer actor；不是先单独验收 Model Domain。
