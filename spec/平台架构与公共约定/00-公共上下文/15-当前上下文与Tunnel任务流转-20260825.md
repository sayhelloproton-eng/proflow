效率纪律：

- 默认 **不创建 checkpoint ZIP**；Git working tree 作为连续整改状态，禁止 `reset / checkout / clean`；
- 默认 **不做中间 format / test / governance**，实时汇报不触发验证；
- 禁止“发现一个 residual 就立刻修一个”，必须先把当前冻结审计范围审完并冻结完整清单；

- CodeGraph 局部 stale 时，以当前磁盘源码为最终真值，只标记对应 graph 结果 stale，不放弃 CodeGraph 整体；
- 独立只读检查允许并行；有依赖关系的修改和 gate 保持顺序；
- 长进程按合理间隔恢复状态并实时汇报是否仍活跃，禁止高频无意义 poll；
- residual list 冻结后若又出现一个完全不同的新 root cause，立即 STOP，重新评估审计方法，而不是继续“下饺子式”整改。

实时汇报继续保留，推荐格式：`[阶段 x/y] 已完成 / 当前 residual 数 / 正在检查 / 进程状态 / 下一步`。

```text

→ 判断 DELIVERED / ABSENT / UNKNOWN
```
