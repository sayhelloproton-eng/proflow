# Phase 3 总纲历史时间线

## 1. 设计与冻结阶段

Phase 3 前期围绕 Task、Agent、Execution、Model、Deployment 五类能力持续收敛领域边界。
Task Journey / Observer、Approval、Browser Carrier、Recovery、Identity 等关键架构裁决最终冻结。
此后原则变为：**不得为了测试变绿重新设计 Frozen Architecture**。

## 2. 系统性非 E2E 收口

2026-08-14 ～ 2026-08-16 进入全量交叉审计与系统性整改收官。
审计方法从单纯代码覆盖升级为：
`真源规范 → 测试计划 → 用例 → API/功能 → Domain/Module/Service 实现 → 实现/测试真实性`。

R3 v3 被定义为最后一次系统性非 E2E 修复候选；之后只允许 Final Narrow Verify。
当固定 root causes、regression 与 packaging 闭环后，正式得到：
`READY_FOR_SMOKE = YES`、`SYSTEMATIC_NON_E2E_REMEDIATION = CLOSED`。

## 3. 从审计驱动切换到真实验收

此后不再允许“失败一次就重新开启 Full Cross-Audit”。
测试主线正式切换为真实 Journey：
`真实执行 → 保存现场 → failure boundary → 最小修复 → targeted regression → 原场景重放`。

Real-1～Real-6 成为 Phase 3 唯一正式收官路线。
## 4. Real-1：Deployment / Registry / Fresh Workspace

2026-08-16 以后 Real-1 成为唯一阶段，Real-1 未 PASS 禁止进入 Real-2。
早期真实黑盒暴露出旧 Platform CLI 把大量 machine-owned facts 当成人工配置的问题，典型包括 `localBaseUrl/publicBaseUrl/stateRoot/databasePath/token/credential/bridge endpoint`。
这促成 Deployment setup 体系重构：Platform 只 discover/order/invoke/aggregate，Module 自己拥有 setup、verify、SETUP.md 与真正的人类动作。

随后 Platform 标准命令面最终冻结为七条：
`install / uninstall / status / setup / docs / start / stop`。
旧 `modules/preflight/verify/doctor/restart` 不再属于标准生命周期。

Real-1 后续经过 Registry 发布、Fresh Workspace、setup UX、七命令合同独立审计与窄整改；2026-08-23 前已完成验收。
因此公共总控状态已从 `Real-1 = NOT PASS` 前进到 `Real-1 = PASS`。

## 5. 当前阶段

下一阶段进入 Real-2：真实 Custom GPT / Worker Identity。
后续不再回头重开 Real-1，除非 Real-2～Real-6 的真实 Journey 给出明确的 Real-1 regression evidence。

## 6. 2026-08-31 Deployment latest 重验与优化收口

在真实 npm latest + 真实 Product Workspace 上重新执行 Deployment 主链后，Browser 0.1.21 的 Chrome restart/live-instance drift、Dev Tunnel、Model FAST/THINK、三个既有 Custom GPT、真实 listeners、repeat setup/start/status 均完成真实验证。

用户最终裁决得到兑现：**主部署链真实跑通即可判 `DEPLOYMENT_SUCCESS=YES`；不阻断主链的 CLI/自动化问题进入后置优化，不再反向卡 Deployment。**

随后 O1～O6 被统一批量整改：默认隐藏 Registry/setup 内部 traversal、Dev Tunnel read-only query 采用 bounded timeout/retry、移除不可信服务计数、收敛 uninstall/默认 CLI 文案。源码提交 `3e91e9b`，版本提交 `e3151f7`；待发布版本为 `platform-cli 0.1.48`、`dev-tunnel 0.1.21`。

因此历史阶段状态变为：Deployment 主链 PASS；当前只剩优化版本发布与发布后 npm latest smoke，完成后回到 Real-3 正式业务 Journey。
