# 真实 E2E 与故障恢复测试计划

## 1. 目标

真实 E2E 只证明 Mock/静态门无法证明的 Carrier、Custom GPT、File Bridge、真实 Effect、Model 与 External Resource reality。它不得重新定义架构。

## 2. 最终 J0→J6 主链

```text
J0 三个泛化 Role READY
→ Extension New Task
→ Task createTask(PENDING)
→ CREATE/observe/bind Product + Dev + Test Workers
→ Product 在 PENDING Task 内完成 Requirement
→ deterministic readiness = READY
→ Extension human confirmation
→ startTask
→ first Node READY
→ Task Observer RESTORE/WAKE bound Worker
→ Worker formal startNode
→ one Worker Turn: GPT Native + 0..N Actions
→ File Bridge / Code Interpreter / Web Search（按需）
→ Execution real Effect / Result / Evidence（按需）
→ Collaboration ask/reply + cross-worker WAKE（按需）
→ complete / true workflow wait / reopen same Worker runNo+1
→ terminal
→ Task Observer stop-driving
```

## 3. Observer E2E/Integration 边界

### Task Observer

必须证明：

- READY/Execution Result READY/Peer Reply READY/Reopen READY deterministic wake；
- 不替 Worker `startNode`；
- terminal no ghost wake；
- 单 Task ambiguity 才进入 REASON diagnostic，模型无 workflow authority。

### System Observer

真实手机 REASON 验证：

```text
bounded 8 views
→ concern batching
→ carry-forward
→ targeted drill-down
→ global synthesis
```

System Observer 低优先级；模型 busy/unavailable 只 defer assessment，不阻断 Task 主链。

## 4. Browser / Carrier 必破坏故障族

- Extension reload / Chrome restart / Content Script navigation；
- tab lost → conversationLocator restore；
- CREATE partial success → only missing Worker retry；
- submit 前 failure → bounded retry；
- submit 后 disconnect → same Conversation reality observation；
- DELIVERED / ABSENT / UNKNOWN 三分；
- DOM drift → screenshot/Vision fallback；
- unexpected ChatGPT permission prompt recovery；
- 禁止 frame registry/iframe topology/persistent tab identity。

## 5. Worker Turn / OpenAI Native

必须真实证明：

- routine Action 在 `x-openai-isConsequential:false` + user-selected Always Allow 后不要求每次 permission；
- 一个 WAKE 后可连续 `0..N` Actions，不出现 Browser “继续”循环；
- Actions 不依赖 arbitrary custom headers；
- c-id/workerRef 仍由 Browser bind/injected typed payload提供；
- File Bridge inbound/outbound hard limits与图片非对称；
- Code Interpreter/Conversation files可用于 bounded Context Pack；
- public research可由 Web Search完成，不要求 Execution generic web search。

## 6. Execution / Collaboration 故障族

- effect_started 后 lost response；
- duplicate command/idempotency conflict；
- UNKNOWN reality reconciliation；
- Execution WAITING_APPROVAL 不自动改变 Task WAIT；
- Collaboration durable message/reply 与 physical delivery分离；
- reply ready 后 WAKE source Worker，不自动改 Task。

## 7. Model / System Assessment 故障族

- FAST/REASON provider unavailable/model_busy/server_paused；
- Task diagnostic structured output invalid/low confidence；
- System assessment single-batch oversized → caller split；
- previous carry-forward stale → current facts win；
- drill-down target unavailable；
- model output recommending illegal mutation → Owner/Policy拒绝。

## 8. Deployment / External Resource

必须覆盖真实 GPT Builder Web-only、Action Auth、Always Allow setup、Chrome Runtime、Dev Tunnel、Model Provider、verify/doctor freshness 与 ACTION_REQUIRED(_WEB)。Human Action 完成后必须 re-observe reality，不能仅凭“用户点过”判 READY。

## 9. 核心不变量

- Owner fact > Observer/Model/Conversation/DOM/log guess；
- 真实 Effect no blind retry；
- existing Worker no duplicate CREATE；
- Reopen same workerRef/Conversation, runNo+1；
- Task start confirmation不是 Task Approval fact；
- Execution dangerous approval 仍由 Execution 持有；
- Browser不从 GPT自然语言推进 Task；
- terminal Task no business wake。
