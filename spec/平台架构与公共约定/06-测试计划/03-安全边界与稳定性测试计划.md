# 安全边界与稳定性测试计划

## 1. Security Boundary Families

### Identity/Auth

- one Role one random credential → Gateway `authenticatedRoleRef`；
- body自报roleRef不可信；
- Browser不持有/校验Role credential；
- `agentPackageRef/roleRef/workerRef/conversationLocator` 与 transient `tabId`分层；
- Task/Node/runNo/workerRef typed payload，不依赖 arbitrary custom headers。

### Files/Secrets

- projectRoot/path traversal/symlink/protected `.proflow`；
- credential/token/cookie/private key不进 Git/Knowledge/Task Markdown/log/Browser wake/Observer model payload；
- File Bridge filename/MIME/URL untrusted；SSRF/private/metadata redirect fail closed；
- Context Pack secret/binary/size filtering。

### Browser

- no frame registry/iframe topology/persistent tab identity；
- DOM-first programmatic input/submit；
- screenshot/Vision只作为观察fallback；
- DOM/Vision不能直接成为Task success truth。

### Approval

- Task start confirmation、Execution Approval、Deployment Human Action、OpenAI Permission四分；
- `x-openai-isConsequential:false` 不能绕过Execution Policy；
- model confidence不能越过DENY/REQUIRE_APPROVAL。

## 2. Stability Families

- SQLite transaction/concurrency/crash reopen；
- idempotency/concurrent duplicate；
- Execution queue/timeouts/cancel/restart/UNKNOWN；
- Browser reload/Chrome restart/locator restore/submit disconnect；
- Worker CREATE partial recovery；
- Collaboration reply/delivery loss；
- single phone model lane、FAST/REASON切换；
- System Observer background defer，不抢占业务推理；
- concern batch oversized、carry-forward、drill-down失败；
- Gateway 45s/100k/File Bridge locator/relay TTL；
- Deployment interrupted apply/verify freshness/ACTION_REQUIRED。

## 3. System Observer Resource Safety

必须证明：

```text
User/business work
> Carrier active operation
> Task Observer/resume
> System Observer
```

System Observer model busy/unavailable只defer，不反压主链；默认只消费摘要/metadata，drill-down按需读取，不把全量日志/源码/文档灌入手机模型。

## 4. 性能阈值

只使用已冻结硬限制。System Observer/REASON 的“有效上下文负载”必须通过真实手机测试建立，不把理论context window直接当生产预算。
